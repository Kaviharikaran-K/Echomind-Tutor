# 🧠 EchoMind AI Tutor

An emotion-aware English learning chatbot powered by Google Gemini AI.

## Features

- ✅ **Emotion Adaptation** - AI adjusts difficulty based on your mood
- ✅ **Grammar Correction** - Gentle corrections with explanations
- ✅ **Secure Backend** - API key protected on server
- ✅ **Real-time Feedback** - See mood and difficulty changes live
- ✅ **Responsive Design** - Works on desktop and mobile
